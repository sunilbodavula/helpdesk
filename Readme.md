# Helpdesk / Ticketing System

Enterprise-style ticketing system built with Spring Boot + React, deployed on AWS.

## Tech Stack
- Backend: Spring Boot 3, Spring Data JPA, Spring Security (JWT), PostgreSQL
- Frontend: React (Vite)
- Infra: Docker, AWS (ECS Fargate, RDS, S3, CloudFront)

## Status
🚧 In development — Day 1: project scaffolding

## Local Setup
1. `docker-compose up -d` — starts Postgres
2. `./mvnw spring-boot:run` — starts backend on :8080
3. Frontend setup — TBD
